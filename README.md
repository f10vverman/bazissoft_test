# Что реализовано
## Маршрутизация

/login — страница авторизации
/dashboard — каталог товаров
`/history` — история покупок
Корневой маршрут `/` перенаправляет на `/dashboard`
Маршруты `/dashboard` и `/history` защищены AuthGuard
## Страница авторизации
Сделал валидацию полей логина и пароля, а так же обработчик ошибок (при ошибке всплывает уведомление об этом). При успехе переходим на `/dashboard`

## Каталог товаров
Оформил таблицу с колонками: ID, Название, Цена, НДС, Действия. Добавление товара через модальное окно, со всеми параметрами. Редактирование и удаление товара. Все изменения сохраняются в `localStorage`. 

## История покупок
Так же таблица с теми же колонками, только добавил еще логин покупателя и дату операции. Все тестовые вводные данные заданы константами. Единственное, что поменял, это интерфейс Purchase:
```
export interface Purchase {
  id: number;
  productName: string;
  username: string;
  price: number;
  vat: number;
  date: string;
}
```
Сделал это, чтобы в логах оставалась истинная цена товара, а не общая сумма вместе с процентом


## Layout
Header с навигацией между сенкциями "Каталог товаров" и "История покупок" и кнопкой выйти. Минимальная адаптивная верстка под планшеты и мобильники

### Технические решения

- Angular 22, SCSS
- Taiga UI v5
- Reactive Forms 
- Signals 
- Lazy-loaded маршруты
- Хранение данных в `localStorage` через отдельный `StorageService`
